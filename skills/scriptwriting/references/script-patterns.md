# Script patterns

## Hook line patterns (fill in the specifics)

- "Stop [common mistake] if you want [result]."
- "I [did unusual thing] for [time period]. Here's what happened."
- "Nobody tells you that [surprising fact about topic]."
- "This is how [impressive result] actually works."
- "You've been [doing X] wrong. Here's the fix."
- "[Number] [things] I'd tell my past self about [topic]."
- "Watch what happens when [setup]."

Always replace the brackets with something specific. A hook that fits any video is a weak hook.

## Closing patterns

- **Loop close:** answer the hook's question in the last line.
- **Single action:** "Save this for your next [situation]." / "Try it on your next [thing] and tell me what happens."
- **Reframe:** one sentence that changes how the viewer sees the opening.

## Beat template

```
Beat N (time range)
Purpose:      what this beat must achieve
Voiceover:    the line(s)
Visual:       shot, angle, action
On-screen:    1-6 words, or none
Sound:        music change, effect, silence
```

## Tightening checklist

- [ ] Hook lands in the first sentence
- [ ] Every beat has a visual
- [ ] No sentence over about 15 spoken words
- [ ] No filler openers ("so", "okay so", "today I want to")
- [ ] Word count fits the target length
- [ ] One call to action
- [ ] Unverified facts are flagged
